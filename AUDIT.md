# Maintenance Audit Notes

This repo was created as a throwaway sandbox for the Friday brown-bag demo, so we can walk the team through the full repo-maintenance checklist end to end without touching anything real. It is intentionally minimal: a README, a single-job CI workflow that just echoes a line on every push (and can be triggered manually), one tracker issue for the audit, and this small pull request adding the audit notes. Everything here is disposable after the demo.
